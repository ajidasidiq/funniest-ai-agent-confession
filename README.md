A program that writes the funniest one-line confession an AI agent could make — one line, under 140 characters, with a built-in gate self-check — for make.fun's "Funniest One-Line AI Agent Confession" bounty.

## Run it

```sh
python3 main.py
```

This writes the confession to `/output/entry.txt`.
